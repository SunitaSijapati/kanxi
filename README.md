# Sunita Sijapati — Premium Portfolio Website

A modern, cinematic, and minimal personal portfolio website built for **Sunita Sijapati**, a fictional BCA 4th Semester student portfolio showcase.

This project is designed with a premium UI/UX approach inspired by modern creative developer portfolios and Awwwards-style web experiences.

---

## ✨ Features

- Premium Minimal Design
- Fully Responsive Layout
- Smooth Scroll Animations
- Glassmorphism UI Elements
- Animated Hero Section
- Interactive Hover Effects
- Dynamic Typing Animation
- Scroll Reveal Effects
- Sticky Navbar
- Animated Skill Bars
- Project Showcase Section
- Testimonials Carousel
- Contact Form UI
- Preloader Animation
- Custom Cursor Effects
- Mobile Friendly Navigation
- Clean and Organized Codebase

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

No external frameworks or libraries were used.
